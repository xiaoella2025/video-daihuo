# video-daihuo 项目规则

## 项目名称

video-daihuo

## 项目目标

复刻视频号图书带货自动成片流程，先完成单条视频从对标素材到竖版带字幕成片的本地工作台。

## 当前 V1 范围

单条视频自动成片，不启用矩阵、多账号批量分发和自动采集。V1 先支持手动上传视频、手动或半自动处理文案、TTS 配音入口、图片上传入口、字幕入口和本地合成入口。

## Claude Code 与 Codex 分工

- Codex：负责初始化项目结构、文档、配置、Git 提交推送和基础工作台骨架。
- Claude Code：后续接手核心开发工作台，包括任务创建、文件流转、视频预览、逐字稿、文案处理、TTS、图片、字幕和合成流程。
- 双方都必须遵守 V1 蓝图，不随意扩大范围或推翻重做。

## 目录分工

- `web/`：本地网页工作台入口。
- `tasks/`：每条视频任务的中间产物目录。
- `assets/`：公共素材、模板、背景音乐和占位图。
- `scripts/`：后续音频提取、字幕生成、视频合成和任务自检脚本。
- `config/`：配置示例和本地配置入口。
- `docs/`：项目规则、V1 蓝图、任务日志和后续说明。

## 禁止事项

- 不要上传 API Key、Cookie、Token、视频号账号信息。
- 不要上传真实视频素材、生成成片、佣金截图。
- 不要随意更换技术栈。
- 不要推翻 V1 蓝图重做。

## 开发规则

- 主分支使用 `main`。
- 不提交敏感信息和本地私有配置。
- 不提交真实视频、音频、字幕、图片任务产物和大体积媒体文件。
- 每个核心能力必须保留单步重跑和中间产物保存思路。
- 重要流程、字段含义和自动化命令必须写入文档。
