# video-daihuo 项目规则

## 项目名称

video-daihuo

## 项目目标

搭建一个本地优先的视频带货工作台，用于沉淀选题、脚本、素材、配置、自动化脚本和交付文档，逐步形成可复用的视频内容生产流程。

## 目录分工

- `web/`：本地网页工作台入口，承载后续可视化操作界面。
- `tasks/`：任务资料、任务输入、执行记录和阶段性产物。
- `assets/`：可复用素材、模板、示例图片或项目资产。
- `scripts/`：自动化脚本和命令模板。
- `config/`：配置示例与本地配置入口。
- `docs/`：项目规则、蓝图、流程说明和决策记录。

## 开发规则

- 主分支使用 `main`。
- 不提交 API Key、账号密码、Cookie、Token 或其他敏感信息。
- 本地私有配置写入 `config/local.config.json`，不进入 Git。
- 临时媒体文件、脚本输出和大体积中间产物不直接提交。
- 每次新增能力前，优先补充文档说明输入、输出、执行方式和注意事项。
- 提交信息使用清晰的中文或英文动宾结构，便于追踪项目演进。

## 协作规则

- 文档先行：重要流程、字段含义和自动化命令需要在 `docs/` 或 `scripts/` 中留下说明。
- 资产可追溯：素材文件应有清晰命名，必要时记录来源、授权方式和使用限制。
- 配置可替换：配置文件仅保存结构与示例值，真实环境值使用本地忽略文件。
