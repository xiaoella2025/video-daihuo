# 视频号图书带货全自动成片工具 V1 蓝图

## V1 总目标

单条视频自动生成竖版带字幕成片，复刻原作者流程，暂时不开矩阵、多账号和自动采集，手动上传视频和图片占位先行。

核心流程：

本地上传对标视频 → 提取逐字稿 → 清洗逐字稿 → 改写口播文案 → 识别书名/作者 → TTS 配音 → 生成/上传配图 → 生成字幕 → 自动合成竖版 MP4 → 预览导出。

## 页面结构

### 1. 任务信息区
字段：
- 任务 ID
- 任务名称
- 原视频标题
- 原视频来源
- 书名
- 作者
- 关键词
- 当前状态
- 当前总成本
- 当前耗时

后续预留字段：
- 账号 ID
- 发布平台
- 发布时间
- 播放量
- 点赞
- 评论
- 商品点击
- 订单
- 佣金
- 是否爆款
- 是否复发

### 2. 视频导入区
V1 必须支持：
- 上传本地视频
- 显示视频预览
- 自动保存原始视频
- 自动生成任务文件夹
- 支持重新上传替换原视频

后续预留：
- 抖音链接输入框
- 自动采集按钮
- 采集失败后转为本地上传

### 3. 逐字稿区
V1 必须支持：
- 从视频提取音频
- 用本地 Whisper 或同类 ASR 生成逐字稿
- 显示原始逐字稿
- 支持手动编辑
- 支持保存
- 支持重新识别

输出：
- raw_transcript.txt
- raw_transcript.json

### 4. 文案处理区

#### 4.1 清洗逐字稿
功能：
- 修复 ASR 错字
- 删除水印、口号、原作者引导关注
- 修正书名、人名、健康词
- 数字转中文
- 补标点
- 去掉重复段落

输出：
- cleaned_transcript.txt

#### 4.2 书名/作者识别
功能：
- 根据逐字稿识别书名
- 识别作者
- 识别国籍/身份
- 显示置信度
- 必须人工确认

输出：
- book_info.json

#### 4.3 口播文案改写
功能：
- 保留爆点
- 保留事实
- 改成适合视频号口播
- 不完全照搬原稿
- 保持字数接近
- 支持多版本保存

输出：
- rewritten_script_v1.txt
- rewritten_script_v2.txt

#### 4.4 轻量去重
功能：
- 微调连接词
- 微调语气
- 不改变事实
- 不破坏爆点
- 为后续复发/矩阵预留

输出：
- dedup_script_v1.txt

当前模式：
- 手动模式：工具生成提示词，用户复制到 GPT，结果粘回工具。
- API 模式：先留配置口子，后期开 API 后一键自动处理。

### 5. TTS 配音区
V1 必须支持：
- 输入最终口播稿
- 支持自动切分长文案
- 支持生成多段音频
- 支持合并音频
- 支持试听
- 支持重新生成
- 支持语速设置
- 支持停顿规则

V1 先做：
- TTS 接口配置入口
- 本地/可用 TTS 兜底
- 支持后续接 index-tts2 API

输出：
- voice_part_001.wav
- voice_part_002.wav
- final_voice.wav

必须保留设置：
- 逗号停顿
- 句号停顿
- 问号/感叹号停顿
- 省略号停顿
- 语速
- 音色
- 数字转中文
- 发音替换词典

### 6. 画面与图片区
V1 必须支持：
- 按口播文案切句
- 每句生成一条画面记录
- 每句可以上传一张图片
- 支持批量上传图片
- 图片自动按顺序匹配文案
- 每张图片可预览
- 每张图片可替换
- 每张图片可标记可用/需替换

手动 GPT 生图口子：
- 工具生成每句生图提示词
- 用户复制提示词到 GPT
- GPT 生成图片
- 用户上传回工具
- 工具继续合成视频

后续 API 口子：
- GPT-Image-2 API 配置
- 九宫格生图
- 自动切图
- 自动匹配 1-9 句

图片记录字段：
- 句子编号
- 口播文案
- 生图提示词
- 图片路径
- 图片状态
- 是否人工替换
- 是否合规
- 备注

输出：
- images/001.png
- images/002.png
- images/003.png
- image_map.json

### 7. 字幕区
V1 必须支持：
- 根据最终口播稿生成字幕
- 根据音频时长自动分配字幕时间
- 支持字幕预览
- 支持手动修改字幕文本
- 支持手动换行
- 支持调整开始/结束时间
- 支持字幕样式设置
- 导出 SRT/ASS
- 合成时烧录字幕

字幕样式：
- 字号
- 字体
- 颜色
- 描边
- 阴影
- 位置
- 每屏字数
- 是否双行

注意：
字幕换行必须允许手动换行，不能系统随便拆。

输出：
- subtitles.srt
- subtitles.ass

### 8. 视频合成区
V1 必须支持：
- 图片 + 配音 + 字幕合成竖版 MP4
- 默认 9:16
- 支持背景音乐
- 支持封面图
- 支持健康声明
- 支持视频声明
- 支持预览
- 支持重新合成
- 支持导出 MP4

当前方案：
- 主合成器：本地 FFmpeg
- 预留：Hyperframes 接口
- 预留：剪映草稿导出

输出：
- final_video.mp4
- cover.png
- task_export.json

## V1 必须保留扩展口子

- 抖音自动采集
- GPT API 自动清洗、改写、轻量去重、书名识别、合规检查、生图提示词
- index-tts2 API
- GPT-Image-2 API
- Hyperframes 合成接口
- 矩阵账号、多版本任务分发、数据回填、爆款复发

## V1 成功标准

1. 本地上传视频 → 自动提取逐字稿。
2. 清洗/改写文案，手动 GPT 模式可用。
3. 识别并确认书名/作者。
4. 生成/上传 TTS 音频。
5. 图片上传/匹配。
6. 字幕生成。
7. 视频合成竖版 MP4。
8. 成片预览。
9. 导出 MP4。
10. 中间产物全部保存。
11. 单步失败可重跑。

## 开发优先级

第一天：
- 工作台页面
- 任务创建
- 本地视频上传
- 任务文件夹生成
- 视频预览
- 逐字稿提取入口
- 原始逐字稿显示/保存

第二天：
- 清洗稿/改写稿编辑区
- GPT 手动复制提示词模式
- 书名/作者识别字段
- TTS 音频上传或生成入口
- 音频试听

第三天：
- 文案切句
- 图片上传/匹配
- 字幕生成
- FFmpeg 合成 MP4
- 成片预览
- 导出

第四天：
- 字幕对齐
- 图片顺序
- 音频时长
- 导出路径
- 失败重试
- 中间文件保存

## 优化点

1. 本地上传兜底。
2. 手动 GPT 模式。
3. 生图手动上传口子。
4. FFmpeg 合成兜底。
5. 每一步可单独重跑。
6. 书名一致性检查。
7. 健康合规提示。
