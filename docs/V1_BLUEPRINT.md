# video-daihuo V1 蓝图

## V1 定位

V1 目标是完成视频带货项目的本地基础设施：项目目录、网页工作台入口、任务沉淀区、素材区、脚本区、配置区和文档区。

当前版本先保证项目可以被 Git 管理、可以推送到远程仓库，并且具备后续扩展自动化生产链路的清晰边界。

## 核心模块

### 1. 本地网页工作台

位置：`web/`

文件：

- `index.html`
- `styles.css`
- `app.js`

用途：

- 提供本地可打开的网页入口。
- 后续承载选题、脚本生成、素材管理、任务状态和执行按钮。
- 初始阶段保持轻量，不绑定后端和外部 API。

### 2. 任务目录

位置：`tasks/`

用途：

- 按任务存放输入资料、执行记录和结果摘要。
- 后续可按商品、账号、平台、日期或任务编号拆分。
- 每个任务的临时产物统一放入 `output/`，避免污染仓库。

### 3. 素材目录

位置：`assets/`

用途：

- 存放可复用视觉素材、文案模板、音频提示、封面参考和其他项目资产。
- 大体积原始媒体建议使用外部存储或临时目录，不直接进入 Git。

### 4. 自动化脚本目录

位置：`scripts/`

用途：

- 存放后续自动化命令模板。
- 可扩展为选题整理、脚本生成、素材归档、视频合成、字幕处理、批量导出等命令。

### 5. 配置目录

位置：`config/`

用途：

- `example.config.json` 保存配置结构示例。
- `local.config.json` 保存本地真实配置，并被 `.gitignore` 忽略。
- 所有敏感值都不得提交到仓库。

### 6. 文档目录

位置：`docs/`

用途：

- 保存项目规则、阶段蓝图、操作流程和重要决策。
- 作为后续自动化和协作的统一说明入口。

## V1 交付清单

- 初始化 Git 仓库。
- 使用 `main` 作为主分支。
- 关联远程仓库 `https://github.com/xiaoella2025/video-daihuo.git`。
- 创建基础目录：`web/`、`tasks/`、`assets/`、`scripts/`、`config/`、`docs/`。
- 创建可运行的本地网页入口。
- 创建任务目录说明、项目规则、V1 蓝图、配置示例和脚本说明。
- 配置 `.gitignore`，避免提交敏感配置、依赖目录、任务输出和临时媒体。

## 后续扩展方向

- 商品与卖点信息录入。
- 视频脚本结构化生成。
- 分镜与镜头清单管理。
- 素材引用与授权记录。
- 批量字幕、配音、合成脚本模板。
- 平台发布文案与标签生成。
- 任务状态看板和产物归档。
