video-daihuo V1

视频号图书带货全自动成片工具 V1

本地优先的单条视频成片工作台骨架，先打通任务、文案、配音、图片、字幕和合成的操作入口。

初始化中
01

任务信息区

记录任务 ID、任务名称、书名、作者、关键词、状态、成本和耗时。

后续接入点：账号 ID、发布平台、播放量、订单和佣金复盘。
02

视频导入区

预留本地视频上传、视频预览、原始视频保存和任务文件夹生成入口。

后续接入点：抖音链接采集、自动采集失败后的本地上传兜底。
03

逐字稿区

承载音频提取、ASR 识别、原始逐字稿显示、手动编辑和保存。

后续接入点：本地 Whisper、重新识别、raw_transcript 输出。
04

文案处理区

管理逐字稿清洗、书名作者识别、口播改写和轻量去重。

后续接入点：手动 GPT 提示词、GPT API 自动处理和合规检查。
05

TTS 配音区

预留最终口播稿输入、长文案切分、多段音频、合并、试听和重生成。

后续接入点：index-tts2、语速音色、停顿规则和发音词典。
06

画面与图片区

按口播切句生成画面记录，支持图片上传、顺序匹配、预览和替换。

后续接入点：GPT-Image-2、九宫格生图、自动切图和 image_map。
07

字幕区

预留字幕生成、预览、文本编辑、手动换行、时间调整和样式设置。

后续接入点：SRT/ASS 导出、字幕烧录和手动换行保护。
08

视频合成区

管理图片、配音、字幕、背景音乐、封面和声明的竖版 MP4 合成。

后续接入点：FFmpeg 主合成器、Hyperframes 和剪映草稿导出。
09

成片预览与导出区

预留最终视频预览、重新合成、导出 MP4 和任务导出记录。

后续接入点：final_video、cover、task_export 和失败重试。
